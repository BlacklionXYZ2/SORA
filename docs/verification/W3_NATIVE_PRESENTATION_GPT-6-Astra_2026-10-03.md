## Contract and authority boundary

The enabled local `CompanionCall` schema now includes `look` and `point`, each with exactly an
operation and a target reference. A native `inspect_window` controls result can expose a Core
issued `t<turn nonce>-c<number>` reference. Reference issuance is based on native observation,
not model-supplied fields. Core records the existing internal target ID and retains native
process identity/geometry privately. Window-list references remain inspection locators and
cannot be substituted as presentation targets.

Only references surviving the actual bounded model-context serialization become selectable.
References are per-turn, bounded and expire. Eligibility excludes password/off-screen/disabled
controls and missing/unverifiable identity/geometry. Final native target revalidation checks
process lifetime, duplicate or changed identity, topology/layout, owner/device/project binding,
static native-read/avatar settings and the current turn fence. Remote sessions gain no such
effect. Failed revalidation/unknown references produce a failed dispatch receipt without a
second action. Read and observation data are not authorization.

The original owner message must request the gesture. Tested quoted/code, negated, hypothetical
and capability-only prompts do not dispatch. The guard is not a complete natural-language
policy proof. No real local-model negative/injection benchmark was run in this checkpoint.

| Operation | Core/renderer behavior | Evidence limit |
| --- | --- | --- |
| `look` | Fresh target revalidation, `look_at` gaze command | Deterministic queue/guard tests, not actual gaze visual review |
| `point` | Fresh target revalidation, `interaction_start` POINT, production reach/retract lifecycle | Actual packaged renderer completion with synthetic target/dialogue |
| Legacy explicit marker | Existing target marker path retained | No behavioral replacement implied |

POINT has no desktop semantic effect: it does not press or type. Chat text says dispatch, not
completed animation. Renderer completion/correlation proves a presentation protocol result,
not native effects or visible animation quality. The production registry explicitly marks POINT
as not changing external state. The command and trace IDs are generated by Core.

Ambient thinking/idle restores are held while the gesture is active, with correlated completion/
failure, disconnect and timeout releasing the hold. The hold is set before awaiting trace I/O.
Attached file/image context no longer excludes the unified chooser; selected-file and extra
context survives read-history refresh. The native branch skips passive image capture and a
second motion decision. These are deterministic regression results, not arbitrary-format file
understanding or a guarantee that every small-model request succeeds.
