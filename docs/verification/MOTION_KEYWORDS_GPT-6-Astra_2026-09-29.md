## Implemented

- One-field `MotionChoice` schema: `motion = none | wave | sit | lean | climb | stand`.
- Existing dialogue model selects the keyword from this turn's owner text in a small separate
  constrained-JSON request. No regex phrase-to-pose implementation is used.
- Strict Core validation and fixed mapping to the managed companion's existing presentation
  states. No model-supplied grants, command IDs, topology, coordinates or OS-effect fields.
- Existing persisted session authority is checked by the normal dispatch path.
- Remote requests and file/image turns skip selection. No history or attachment data enters the
  selector. None continues normal conversation; malformed model output fails closed.
- Responses acknowledge dispatch only, never completed animation. None replies get a truthful
  Core-provided description of the available keyword interface.
- Explicit requested pose is retained as the resting state across thinking/waiting transitions.

## Honest limits / perception answer

Renderer-state feedback proves the command path, not visual quality, physical contact or animation
completion. Only the listed live prompt set was evaluated; no general intent-classification accuracy
or adversarial-proof claim is made. The prototype adds a classifier call before normal conversation
when the local avatar is configured. Other compatible model servers/builds were not tested.

Desktop/window/file access was inspected in current code and its existing mocked regression tests
rerun; it was not broadened. Ordinary chat does not automatically capture a screen or enumerate
windows. The separate Look at screen path performs one explicit local vision capture. The manual
launcher configures that capture helper, not the separate process-scoped Windows UIA bridge.
Attachments and narrow `read file <path>` commands support readable regular local files with format
and payload limits, not model-driven file discovery. No new private desktop capture was needed for
this implementation. See `docs/runbooks/SORA_MOTION_KEYWORDS.md` for the full interface matrix.
