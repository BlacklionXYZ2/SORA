## Changes implemented

### Volatile capture contracts and storage

- Extended cursor samples with strict button, topology, monotonic-time and optional element metadata.
- Replaced the capacity-only cursor buffer with capacity and wall-clock bounds, ordered batch ingestion, pruning, explicit last-seen/expiry state and lifecycle clearing.
- Added bounded semantic selection history plus typed cursor batch, selection, resolution request, resolution result and status contracts.
- Extended short-lived attention targets with project, topology, desktop-target and provenance fields while requiring positive rectangles and a real lifetime.
- Published and refreshed the corresponding deterministic JSON schemas.

### Gesture and attention resolution

- Added bounded press/release click recognition that rejects long holds and excessive movement.
- Retained hover recognition and hardened circle recognition with duration, velocity, path-length, closure, area and winding checks.
- Resolves fixture hover, click, selection and circle input to expiring owner/device/project/topology-scoped attention targets.
- Returns typed `no_data`, `expired` and `rejected` outcomes rather than guessing when buffers, timing, topology or geometry do not support a target.

### Authorization, API and privacy

- Added exact persisted observation grants for cursor ingress, selection ingress and attention resolution.
- Validates capture age, active-display containment, topology revision, optional desktop-target scope and cross-batch ordering before grant consumption.
- Clears raw samples on topology changes and runtime shutdown.
- Added local HTTP routes and SDK methods for cursor, selection and resolution operations.
- Added unique-sentinel acceptance proving raw labels are absent from trace fields and SQLite.

### Verification repair

- Fixed `scripts/verify.ps1` so a failing native `uv` command terminates the repository gate instead of allowing later commands to mask it.
- Regenerated the six new or changed P10.5 public schemas and reran the corrected gate.

### Tests and documentation
