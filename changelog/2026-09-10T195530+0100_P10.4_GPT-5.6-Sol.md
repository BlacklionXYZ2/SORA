## Changes implemented

### Editor contracts and task binding

- Added strict contracts for editor positions, selections, context requests/snapshots, editor task submission, structured findings and finding presentation.
- Extended task records with an optional verified editor snapshot and normalized provider results with optional typed editor findings.
- Published JSON schemas for each new editor contract and refreshed the task/result schemas.
- Added a deterministic `EDITOR_CONTEXT` context source ahead of conversation history and fail the run if a verified selection cannot fit the provider context budget.

### Verification and privacy boundary

- Added repeatable `--editor-root` configuration; the managed Codex repository is also eligible when configured.
- Requires a persisted exact/path-contained `path.read` grant and consumes it before reading the selected file.
- Verifies configured-root containment, resolved file identity, 2 MiB read bound, UTF-8 encoding, saved-document SHA-256, one-based/end-exclusive selection bounds, exact canonical-LF text and a 60-second capture age.
- Requires the associated volatile desktop target to have the same owner/device/project scope.
- Persists the bounded exact selection with the task under normal retention, while traces contain no repository path or selected text.
- Marks editor tasks local-only so private selected code cannot silently route or fall back to a cloud provider.

### Finding presentation

- Added `POST /api/v1/editor/tasks` and client support for exact editor-context tasks.
- Added `POST /api/v1/tasks/<task-id>/editor-finding` and client support for pointing at a completed result's structured finding.
- Rejects failed/unrelated results, selection-digest changes, findings outside the selection and caller-invented finding IDs before any presentation grant is consumed.
- Revalidates current UIA target identity and geometry under a fresh exact `desktop.present:<target-id>` grant, then maps the finding lines to a proportional marker rectangle.
- Performs no editor mutation, focus change, input synthesis or UIA invocation.

### Tests and documentation

- Added a file-backed cooperating-editor fixture proving exact selected bytes reach the task and provider request.
- Added changed-document, guessed-selection, unconfigured-root, invented-finding and incomplete-metadata failures.
- Added route-level submission and finding presentation acceptance.
- Updated the implementation plan and Windows bridge/editor-boundary documentation while preserving Astra's P10.1 and earlier P10.2–P10.3 attribution.
