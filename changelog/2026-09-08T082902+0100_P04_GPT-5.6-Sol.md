## Changes implemented

- Corrected provider capability reporting: sessions, resume, and cancellation are supported;
  `events=false` because SORA does not yet expose a provider event stream; tool restrictions remain
  explicitly unsupported.
- Added native Hermes session-ID capture and bounded retention, plus resume through ACP
  `session/load`.
- Fixed a live-discovered resume defect by discarding history chunks replayed during
  `session/load` before collecting the new prompt response.
- Added ACP `session/cancel`, a bounded cancellation grace period, and terminate/kill fallback.
- Made repeated starts idempotent and made completed, failed, and cancelled lifecycle status
  reporting robust.
- Required an explicit existing `--hermes-cwd` before database initialization, preventing a Hermes
  task from silently inheriting the SORA checkout.
- Set `HERMES_ACP_SKIP_CONFIGURED_MCP=1` for child processes and added conformance coverage for the
  environment contract.
- Added explicit rejection of ACP client filesystem/terminal methods, agent tool events, tool
  updates, and permission requests. The adapter now fails closed instead of accepting toolful
  output.
- Enforced ACP protocol version 1 negotiation and a default 65,536-character output ceiling.
- Tightened known-field parsing so malformed lists fail rather than vanish; preserved valid
  `files_read`, `commands_run`, and `warnings` output.
- Reclassified model-suggested facts from certain observations to `inference` with confidence 0.5.
- Corrected owner-only fact patch scope from `owner/global` to `owner` while retaining
  `owner/project` for project-scoped updates.
- Made runtime timeout text provider-neutral and made interactive provider labeling accurately
  distinguish the deterministic mock from external Hermes ACP.
- Expanded Hermes and CLI tests for parsing, patch scope, typed launch failures, exact protocol
  exchange, environment, idempotency, output limits, tool rejection, protocol cancellation, native
  resume, load-time replay, and required cwd behavior.
- Updated ADR 0005, README usage/safety guidance, the implementation plan, and P04 verification
  evidence while preserving the historical GPT-5.6 Luna changelog.

## Post-completion trust-policy amendment — 2026-09-08

The user clarified that Hermes is trusted to manage its own native tools, as Codex and Antigravity
do. The adapter now accepts native-tool activity, preserves globally configured MCP integrations by
default, and selects ACP `allow_once` permissions when available. Restricted operation is explicit
through `--hermes-deny-approvals` and `--hermes-skip-configured-mcp`. The earlier no-tool live matrix
remains valid evidence for reasoning/session/cancellation behavior; later live tool probes timed out,
so this changelog does not relabel them as successful tool runs. See the separate model-attributed
amendment changelog for exact implementation details.
