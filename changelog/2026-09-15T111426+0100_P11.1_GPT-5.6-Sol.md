## Changes implemented

- Added Core contract states for thinking, listening, speaking, waiting for an agent, reading and
  typing; kept moving/looking derived rather than directly settable.
- Added optional presentation style and semantic-action profile metadata with strict validation and
  no authority semantics.
- Added a data-driven Unity `PresentationProfileRegistry` for replaceable state/action/style
  mappings, including blend, retraction, gaze, reach, arm and torso-pose parameters.
- Added `AvatarPresentationController`, a profile-driven torso pose layer. `THINKING` is registered
  as data and does not require a state-specific controller branch.
- Added `AvatarReachController` with live humanoid-bone binding, two-bone arm/fingertip IK, nearest or
  preferred arm selection, reachability bounds, weighted gaze, blending, retraction, interruption,
  and base-pose restoration.
- Wired the presentation and reach components into the runtime-loaded VRM bootstrap.
- Hardened the C# command consumer so unknown/derived states, unknown actions/phases and malformed
  styles are rejected before Unity main-thread dispatch.
- Added Python contract tests, portable C# transport tests and Unity PlayMode fixtures for dynamic
  THINKING registration, style fallback, left/right reach, out-of-reach rejection and interruption.
- Regenerated the affected public v1 schemas and updated the implementation plan and Unity operator
  documentation.
