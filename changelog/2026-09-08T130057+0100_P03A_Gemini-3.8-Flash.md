## Changes implemented

### 1. Public Contracts & Schemas (`src/sora/contracts/`, `contracts/schema/v1/`)
- Extended `ProviderCapabilities` with additive fields: `streaming`, `filesystem`, `worktree_support`, `structured_output`, and `display_name`.
- Added contract models and StrEnums:
  - `CapabilityCategory`, `CapabilityScope`, `SemanticVerb`, `PresentationMode`, `SemanticActionPhase`, `DesktopObjectVisibility`, `ExtensionDepth`.
  - `CapabilityDescriptor`: parameter schema, scope, risk level, required grants, timeouts, and idempotency guarantees.
  - `CapabilityIndexEntry`, `CapabilityIndex`: compact discovery projections without prompt bloating.
  - `CapabilityResolutionRequest`: request containing active grants, scope constraints, and budget limits.
  - `ActiveCapabilityManifestEntry`, `ActiveCapabilitySet`: dynamically resolved capabilities with active schemas and expiration timestamps.
  - `ResultPresentation`: adaptive presentation mode (`SILENT`, `BRIEF`, `EXPLAIN`, `WALKTHROUGH`), significance, physical cues, and attention requirements without leaking scratchpads.
  - `AttentionTarget`: spatial attention targets with screen rectangles, confidence scores, and strict aware timestamp lifecycle validation.
  - `DesktopObjectRecord`: virtual desktop object records with anchors, affordances, and visibility scopes.
  - `SocialEventRecord`: external network interaction records marked with trust classifications.
  - `NetworkProfileProjection`: privacy-preserving public persona projections.
  - `ExtensionRegistration`: structured extension manifests with configuration and grant dependencies.
- Registered all 10 new models in `PUBLIC_CONTRACTS` (`src/sora/contracts/registry.py`) and generated corresponding JSON Schemas in `contracts/schema/v1/`.

### 2. Capabilities Subsystem (`src/sora/capabilities/`)
- Implemented `CapabilityRegistry` to store and query descriptors across categories (`TOOL`, `MEDIA`, `DESKTOP_OBJECT`, `EXTENSION`, `SOCIAL`).
- Implemented `CapabilityResolver` with budget-constrained relevance scoring and strict scope containment (`LOCAL_OWNER`, `LOCAL_RESTRICTED`, `NETWORK_PUBLIC`, rejecting `REMOTE_GUEST`).
- Implemented `dispatch_capability` with active set membership verification, grant validation, and TTL expiration enforcement, raising typed `CapabilityDeniedError`.

### 3. Context Compiler Extension (`src/sora/context/compiler.py`)
- Extended `compile_context` with `privacy_scope="network_public"` filtering, excluding non-public items with auditable manifest entries (`reason="privacy_scope_excluded"`).
- Added rendering for `[ACTIVE_CAPABILITIES]` within compiled context blocks when active capability sets are supplied.

### 4. Attention & Gestures (`src/sora/attention/`)
- Implemented `CursorRingBuffer`: volatile, in-memory, bounded ring buffer of timestamped cursor samples, enforcing timezone-aware timestamps.
- Implemented timestamp-based sample lookup with configurable tolerance and recent window sample retrieval.
- Implemented `detect_hover`: centroid calculation for dwell periods >= min_duration within distance thresholds.
- Implemented `recognize_circle`: closed-loop circling gesture recognition returning bounding boxes, filtering linear or non-closed trajectories.

### 5. Desktop Objects (`src/sora/desktop_objects/`)
- Implemented `KanbanBoardProjection` and `project_tasks_to_kanban`: deterministic projection from canonical `TaskRecord` collections onto Kanban columns (`TODO`, `DOING`, `DONE`) with specialist assignment and attention flags.

### 6. Social Boundary & Privacy (`src/sora/social/`)
- Implemented `project_public_profile`: isolated projection of public identity (`NetworkProfileProjection`) without leaking system files or internal state.
- Implemented `ingest_social_event`: converts external social events into untrusted observation items (`ContextSource.MEMORY`), never authoritative facts.
- Implemented `validate_outbound_social_payload`: verifies outbound payloads against private sentinels and credentials with case-insensitive rejection.

### 7. Dialogue & Runtime Layer (`src/sora/providers/dialogue.py`, `src/sora/runtime/`)
- Defined `DialogueProvider` protocol and implemented `DeterministicDialogueProvider`.
- Extended `SoraRuntime` with direct companion methods:
  - `dialogue(text: str)` and `stream_dialogue(text: str)`: responsive conversation that runs concurrently while background reasoning workers are active.
  - `dialogue_status()`: reports dialogue availability independently of worker queues.
  - `active_specialists()`: inspects active runs (`PENDING`, `LAUNCHING`, `RUNNING`) in `RuntimeRepository`.
  - `present_result()`: computes adaptive `ResultPresentation` modes (`SILENT`, `BRIEF`, `EXPLAIN`, `WALKTHROUGH`) without exposing private scratchpads.

### 8. Comprehensive Automated Tests
- Added `tests/capabilities/test_capabilities.py` (9 tests): scope containment, budget enforcement, contextual scoring, dynamic schema generation, grant checks, and TTL expiration.
- Added `tests/runtime/test_companion_ux.py` (3 tests): dialogue availability during slow background tasks, active specialist reporting, steering trace recording, and adaptive presentation mode selection.
- Added `tests/attention/test_attention_objects.py` (6 tests): ring buffer bounds and sample lookups, hover and circle gesture recognition, AttentionTarget contract validation, and Kanban task projections.
- Added `tests/social/test_social_privacy.py` (4 tests): network_public context exclusion, public profile projection, untrusted social event labeling, and outbound payload sentinel validation.
