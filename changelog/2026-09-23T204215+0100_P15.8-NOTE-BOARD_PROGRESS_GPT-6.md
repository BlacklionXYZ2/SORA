- Replaced the desktop board's grid/text compact mode with a small cork-style,
  three-note preview. Clicking it opens three sticky-note lanes labeled TODO,
  IN PROGRESS and COMPLETED; Minimise returns to the small board.
- Added note colors for Codex, Claude, Hermes, Antigravity and SORA, plus a neutral
  unassigned tint. A selected note can be assigned, moved to a chosen column,
  soft-removed, started if planned, or retried if failed/cancelled/interrupted.
- Added schema-9 `board_cards` and `board_card_events` tables. Board column and
  assignment are separate from the canonical task/run status. Remove hides the
  board card but retains task, run, result and event history; edits record actor,
  version and time. Owner-local Core routes validate scope and allowed values,
  and the desktop sends an expected version so stale owner edits conflict.
  Existing tasks use their actual specialist as the note-color fallback until
  explicitly reassigned on the board.
- Added exact local SORA dialogue commands for add/assign, move and remove.
  Remote dialogue does not execute these commands. Claude is a visual assignment
  only until a provider is registered, and starting a Claude-assigned note is
  explicitly refused rather than silently rerouted.
- Added API tests for edit validation, lifecycle separation, soft removal,
  audit, SORA commands and the remote-dialogue boundary, plus a C# projection
  test. The first visual pass found a clipped third preview and overcrowded
  action strip; both were corrected and rechecked in the native window.
