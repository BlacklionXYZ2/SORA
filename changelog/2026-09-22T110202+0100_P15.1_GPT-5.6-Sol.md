# P15.1 responsive local PWA — GPT-5.6 Sol

Completed: **2026-09-22 11:02:02 +01:00**.

## Changes

- Added a packaged build-free PWA with a responsive conversation-first layout, install manifest,
  generated PNG icons, accessible controls and reduced-motion handling.
- Added canonical conversation, provider/task, steer/cancel and optional payload-free trace views.
- Preserved user-then-assistant display order for equal-timestamp turns using durable insertion order
  instead of random UUID tie-breaking.
- Added a visibly qualified browser speech-recognition control without representing it as P14's
  local voice pipeline.
- Added memory-only bearer authentication and network-only API requests; credentials are absent
  from URLs, cookies, persistent browser storage and caches.
- Added an exact-allowlist app-shell server and restrictive CSP/referrer/content-type policies.
- Added bounded authenticated HTTP event replay for browsers, including expired, gap and
  future-cursor resynchronization without weakening WebSocket authentication.
- Added authoritative projection reconciliation after initial connection, reconnect and changes.
- Added server and service-worker no-store defenses for API, health and readiness data.
- Added live Core/API acceptance, zero-dependency browser tests, deterministic icon generation and a
  PWA verification script integrated into the repository gate.
- Updated the README, implementation plan and P15.1 verification evidence.
