## Changes implemented

- Added Pydantic as the first runtime dependency and refreshed the exact `uv.lock` to 18 packages.
- Implemented strict, immutable public contract version `1.0` with bounded identifiers/text,
  offset-aware timestamps, forbidden extra fields, and lifecycle validation.
- Added separate task, agent-run, and agent-session records. Task retry is a recorded transition back
  to queued; terminal runs remain terminal and another attempt requires a new run.
- Defined task, run, and approval transition matrices covering reasoning/working, permission/input
  waits, cancellation races, interruption, uncertain recovery, retry, and terminal states.
- Added backend-neutral provider capabilities, requests, errors, normalized results, and a
  `ReasoningProvider` protocol. Unsupported methods and unavailable, malformed, rate-limited,
  timed-out, cancelled, lost-session, and uncertain-launch outcomes remain typed.
- Added typed proposed fact, memory, and task-metadata operations in versioned patch envelopes. Patch
  preflight distinguishes applicable, duplicate-idempotency, and entity-version conflict outcomes.
- Added durable event envelopes and deterministic first, next, duplicate, stream-mismatch,
  regression, and gap classification.
- Added capability requests/grants scoped to owner, device, project, operation, absolute path or
  exact tool/action resource, validity window, status, and use limit.
- Implemented deterministic authorization with resolved path containment, including sibling-prefix
  escape rejection. Only typed grants convey authority; injected or unknown fields fail closed.
- Added terminal approval handling. Late decisions expire and completed decisions cannot be changed.
- Added recursive structured redaction for configured secrets, API key/token/password patterns, and
  bearer credentials before capability audit logging.
- Published 11 generated JSON Schemas, 11 valid shared examples, and adversarial scenarios for
  duplicate events, stale patches, malformed output, uncertain launch, lost session, and native
  backend field leakage.
- Added deterministic schema generation/freshness checking to the standard Windows verification
  workflow.
- Published compatibility, retry, cancellation, idempotency, ordering, and authority rules in
  `contracts/README.md` and ADR 0002.
- Corrected the P00 changelog filename and attribution to use the requested model name,
  `GPT-5.6 Sol`, rather than model-ID wording.
