## Changes

- Added a separate opt-in TLS-only remote listener while keeping the owner listener and bearer
  permanently loopback-only.
- Added fail-closed configuration for concrete non-public bind addresses, certificate/private key,
  exact HTTPS browser origins and exact optional host names; public, wildcard and plaintext remote
  configurations are rejected.
- Added persisted one-time pairing invitations, paired devices, short-lived sessions, revocation and
  bounded remote-access audit state in schema migration 7.
- Added hashed high-entropy invitation/device/session secrets, transactionally single-use claims,
  subset-only session scopes and per-request expiry/revocation checks.
- Added an exact remote route-to-scope allowlist. Default pairing omits task control; sensitive and
  unlisted surfaces are absent, remote WebSockets are disabled and remote events omit payloads.
- Added per-source general and pairing/session rate limits plus redacted owner-only audit inspection.
- Added Python SDK support for HTTPS, device/session schemes, pairing administration and revocation.
- Extended the PWA with owner invitation/device/revoke controls, remote pairing, automatic
  short-session renewal and origin-scoped IndexedDB storage for only the long-lived device
  credential. Owner and session credentials remain memory-only and out of URLs/caches.
- Added deterministic TLS fixtures and security, scope, replay, expiry, concurrent claim, rate-limit,
  audit, restart and revocation tests; extended PWA runtime and package checks.
- Added ADR 0011, operator documentation and machine-readable acceptance evidence.
