## Changes Implemented

### 1. Antigravity CLI Adapter (`src/sora/providers/antigravity.py`, `src/sora/providers/__init__.py`)
- Implemented `AntigravityProvider` wrapping non-interactive Google Antigravity CLI (`agy.exe`):
  - Flags: `--output-format json`, `--effort <low|medium|high>`, `--print="..."`.
  - Native session persistence: parses `conversation_id` from the structured JSON response and supports session resumption via `--conversation <id> --continue`.
  - Process lifecycle & safety: clean termination of child processes upon cancellation or timeout, `ProcessLookupError` handling, and configurable output ceiling (`max_output_bytes`).
  - Response normalization: implemented `parse_antigravity_result` to parse structured JSON or fallback raw text into `NormalizedResult`, rejecting malformed envelopes with typed `ProviderResultError`.
- Exported `AntigravityProvider` and `parse_antigravity_result` from `src/sora/providers/__init__.py`.

### 2. Deterministic Routing Engine (`src/sora/routing/`, `src/sora/routing/router.py`)
- Implemented `RoutingEngine`, `RoutingDecision`, and `TaskIntentCategory`:
  - **Fast-paths**: implemented synchronous `dialogue_fast_path` and `status_lookup_fast_path` to bypass worker queues for instant responses.
  - **Intent Classification**: classified user requests into `research`, `coding_read`, `coding_write`, `deterministic_offline`, or `reasoning_general`.
  - **Explicit Manual Override Protection**: explicit user requests for a backend (`hermes`, `codex`, `antigravity`, `mock`) are never silently substituted. If the backend is unavailable, `ProviderLaunchError(UNAVAILABLE)` is raised with an empty fallback list.
  - **Privacy Scope Containment**: local-only context filters out cloud providers and rejects explicit cloud requests.
  - **P05.3 Safety Boundary**: marks coding writes with `p05_deferred=True` and holds in-place mutations pending P05.3 worktree isolation.
  - **Conversational Steering Disambiguation**: implemented `disambiguate_steering` to map natural references ("Cody", "Hermes", "Antigravity"/"AG", or pronouns) to the exact active task run when unambiguous, returning `None` when ambiguous.
- Exported routing components from `src/sora/routing/__init__.py`.

### 3. Runtime Multi-Provider Integration (`src/sora/runtime/repository.py`, `src/sora/runtime/service.py`)
- Extended `RuntimeRepository.submit` with `requested_backend: str | None = None` to record explicit overrides vs automatic routing.
- Extended `SoraRuntime`:
  - Multi-provider registry (`self.providers`) supporting dynamic registration and capability discovery at `start()`.
  - Event trace recording: emits `phase="routing.selected"` on task submission and `phase="routing.fallback"` on bounded automatic fallback.
  - Execution dispatch: runs tasks using the run's recorded backend provider.
  - Conversational steering (`runtime.steer_from_conversation`): routes steering commands directly to disambiguated active runs.
  - Adaptive presentation (`runtime.present_result`): dynamically selects `BRIEF`, `EXPLAIN`, or `WALKTHROUGH` presentation modes with specialist attribution.
