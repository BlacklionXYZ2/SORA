## Changes implemented

- Added `DesktopPressRequest`, `DesktopActionStatus` and `DesktopActionResult` public contracts and
  generated their v1 JSON Schemas.
- Extended volatile desktop targets with enabled-state evidence and added internal Level 3
  `DesktopAuthority.INTERACT` revalidation using the existing distinct `desktop.interact` capability.
- Added SQLite migration 5 and repository compare-and-set methods for durable action reservation,
  execution claims, terminal results and startup recovery of unfinished attempts.
- Added `SoraRuntime.press_desktop_target` and
  `POST /api/v1/desktop/targets/<target-id>/press`, plus Python and Unity client methods.
- Bound authorization to exact resource `desktop.interact:<target-id>:press`; Core consumes and
  rechecks persisted grant/approval evidence at contact rather than accepting caller provenance.
- Added fresh UIA process/control/topology/enabled/name/rectangle checks and aborts when a target
  moved or changed after the reach target was selected.
- Added the separately configured `clients/windows_action` .NET 10 helper. It is shell-free,
  non-elevating, one-shot, bounded, credential-free, exact-identity checked, and supports only UIA
  `InvokePattern.Invoke` for PRESS.
- Extended the owned WinForms fixture with a visible accessible-name postcondition and press counter.
- Added `AuthorizedPressAction`, an independently registered P11 Unity component that delegates the
  effect to Core and feeds Core's failed/completed/unknown evidence into the unchanged generic
  lifecycle. Extended the lifecycle component contract so authoritative no-effect replies remain
  failures rather than being inflated into unknown outcomes.
- Added deterministic authorization, expiry, movement, disabled-target, revocation, duplicate,
  conflict, cancellation, crash-recovery, worker-protocol and Unity outcome fixtures, plus a real
  native UIA invocation proving that duplicate contact does not press twice.
- Added `--windows-action` runtime configuration and native desktop verification/build coverage.
