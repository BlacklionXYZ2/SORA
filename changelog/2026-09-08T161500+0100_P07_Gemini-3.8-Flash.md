## Overview

Phase P07 completes the G2 Agent Workbench milestone by delivering:
1. Complete Git workspace lifecycle management (`sora.workspaces.git`): tracking, inter-workspace diffs, lease renewal, crash recovery with snapshot preservation, path containment, dirty discard protection, and expired lease cleanup.
2. Bounded multi-candidate fan-out & deterministic synthesis (`sora.workspaces.synthesis`): concurrent candidate provider execution in isolated branch runs and dedicated worktrees, deterministic consensus classification, transparent failure exposure, and non-authoritative recommendations without candidate command execution.
3. Review & integration workflow (`sora.workspaces.review`): pre-integration conflict detection, validation command suites, strict authorization gating (`authorized_by` non-empty), atomic patch application (`git apply --index`) preserving untracked checkout work, and documented rollback.

## Changes Implemented

### 1. Workspace Manager Lifecycle (`src/sora/workspaces/git.py`)
- Added `WorkspaceStatus` enum: `ACTIVE`, `RELEASED`, `RECOVERED`, `DISCARDED`.
- Extended `WorkspaceRecord` with `status: WorkspaceStatus`.
- Implemented `list_workspaces()` returning all active/known workspace records.
- Implemented `diff_workspace(workspace_id)` and `diff_between_workspaces(ws_a, ws_b)` to inspect changes without mutating working trees.
- Implemented `renew_lease(workspace_id, lease_owner, extend_seconds)` with strict single-writer ownership verification.
- Implemented `recover_workspace(workspace_id, reason)`: captures complete diff and untracked file snapshots into durable recovery artifacts on crash or lease abandonment, unlinks active lease, and marks workspace `RECOVERED`.
- Implemented `discard(workspace_id, force=...)`:
  - Path containment: strictly checks worktree path against workspace state root, raising `WorkspacePathEscapeError` if outside bounds.
  - Dirty protection: prohibits discarding uncommitted work unless `force=True`, raising `WorkspaceDirtyDiscardError`.
  - Zero-data-loss snapshot: captures an automatic recovery artifact prior to worktree removal when `force=True`.
- Implemented `cleanup_expired()`: iterates known workspaces, releasing clean expired workspaces and capturing recovery snapshots for dirty expired workspaces.
- Added `_git_diff()` helper safely handling git diff exit codes (0 = no diff, 1 = diff present).

### 2. Multi-Candidate Synthesis Engine (`src/sora/workspaces/synthesis.py`)
- Defined `SynthesisConsensus` enum: `FULL_AGREEMENT`, `PARTIAL_AGREEMENT`, `DISAGREEMENT`, `PARTIAL_FAILURE`, `ALL_FAILED`.
- Defined `SynthesisCandidate` and `SynthesisResult` models.
- Implemented `SynthesisEngine`:
  - Deterministically evaluates candidate outputs without inventing artificial consensus.
  - Surfaces candidate failures, exit codes, and diff divergences transparently.
  - Treats conclusions as non-authoritative recommendations: synthesis never executes candidate tool commands or mutates target repositories.

### 3. Review & Integration Subsystem (`src/sora/workspaces/review.py`)
- Defined `IntegrationStatus` enum: `PENDING`, `VALIDATED`, `CONFLICT`, `INTEGRATED`, `ROLLED_BACK`, `FAILED`.
- Defined `ConflictReport`, `ValidationReport`, and `IntegrationRecord` models.
- Defined typed exceptions: `IntegrationError`, `IntegrationConflictError`, `IntegrationAuthorizationError`, `IntegrationValidationError`.
- Implemented `ReviewManager`:
  - `check_conflicts(workspace_id)`: tests whether candidate patch applies cleanly to current target HEAD using `git apply --check`.
  - `validate(workspace_id, commands)`: runs pre-integration test/validation commands in the workspace directory.
  - `integrate(workspace_id, authorized_by, ...)`: enforces explicit authorization (`authorized_by` non-empty), verifies target repository cleanliness, applies git diff atomically via `git apply --index`, records commit/patch metadata, and preserves untracked files in the target repository.
  - `rollback(integration_id)`: safely reverts integrated patches, verifies clean repository state, and updates durable integration status to `ROLLED_BACK`.

### 4. Workspaces Module Exports (`src/sora/workspaces/__init__.py`)
