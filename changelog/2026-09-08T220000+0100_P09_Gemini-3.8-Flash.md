## Overview

Phase P09 establishes SORA's **Embodiment and Desktop Awareness Foundation**:
1. **Multi-Monitor Coordinate Foundation (`sora.embodiment.coordinates`, `CoordinateTransformer.cs`)**:
   - 4-level spatial hierarchy: Global Desktop Space (GDS), Monitor Identity Resolution with Gap Clamping, Monitor-Local Space (MLS), and Unity World Space (UWS) with decoupled per-monitor DPI scaling.
   - Bidirectional reversibility with $\le 1\text{ physical pixel}$ round-trip accuracy across all display configurations.
   - Shared canonical fixtures in `contracts/fixtures/coordinate_fixtures.json` validating 8 display topologies across Python and C#.
2. **Empirical Win32 Presentation Spike (`clients/win32_spike`)**:
   - Evaluated Strategy A (Per-Monitor Surfaces) vs Strategy B (Single Virtual Desktop HWND).
   - Validated live on physical dual-monitor hardware (`DISPLAY6` portrait at $[-1280, 813]$, `DISPLAY1` landscape 4K at $[0, 0]$).
   - Confirmed DWM glass transparency (`DwmExtendFrameIntoClientArea`) and `WM_NCHITTEST` returning `HTCLIENT` over avatar visual elements and `HTTRANSPARENT` over background desktop areas.
3. **Core Embodiment API (`sora.contracts.embodiment`, `sora.api.routes`, `sora.runtime.service`)**:
   - Exposed `GET /api/v1/projections/embodiment`, `POST /api/v1/embodiment/command`, and `POST /api/v1/embodiment/topology`.
   - Enforced topology revision checks (`STALE_TOPOLOGY_REVISION` HTTP 409) preventing stale coordinate execution.
4. **Unity Embodiment Client Suite (`clients/unity/Assets/Scripts/`)**:
   - `Native/WindowPresentation.cs`: Borderless popup window styling, DWM alpha transparency, topmost z-order, and `WM_DISPLAYCHANGE` hooking.
   - `Network/SoraCoreClient.cs`: Asynchronous `ClientWebSocket` event loop with sequence replay, `resync_required` handling, and topology update reporting.
   - `Avatar/AvatarLocomotion.cs`: Deterministic avatar ground-plane locomotion across monitor seams without model inference in the 60 FPS update loop.
   - `Avatar/AvatarLookAt.cs`: Anatomic clamped gaze controller ($[-60^\circ, +60^\circ]$ yaw, $[-30^\circ, +30^\circ]$ pitch).
   - `Avatar/AvatarHitTest.cs`: Collider raycasting hit-test component.
   - `Debugging/DebugOverlayHUD.cs`: Toggleable F12 HUD displaying real-time topology, world/desktop coordinates, hit-test status, and connection health.
