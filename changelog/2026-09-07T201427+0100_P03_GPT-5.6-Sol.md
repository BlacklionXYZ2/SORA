## Changes implemented

- Added the asynchronous SORA application runtime and a clearly labeled deterministic mock CLI.
- Added interactive and one-shot task flows, asynchronous deterministic dialogue chunks, task wait,
  cancel, steer, retry, and message/task/state inspection.
- Added atomic, capacity-bounded, idempotent submission of the originating message, stable
  acknowledgement, task, first run, events, and outbox records.
- Added a bounded FIFO worker queue, persisted leases/deadlines, timeout handling, coherent terminal
  waits, explicit capped retries, and immutable run-attempt history.
- Added startup reconciliation for every prior-process lease, including unexpired crash leases,
  without automatically relaunching uncertain effects.
- Added deterministic fault modes for delay, failure, rate limiting, malformed result, disconnect,
  cancellation race, uncertain launch, and provider unavailability.
- Added typed unsupported steering, supported steering delivery, cancellation reconciliation, and
  retention of late cancellation results without patch application.
- Added grounded status reporting that never describes pending, failed, unavailable, or cancelled
  work as completed.
- Added message→task→run→result→patch traces with correlation IDs, context-selection metadata,
  latency, and configured secret redaction.
- Added at-least-once outbox dispatch with delivery marking only after consumer success.
- Added schema migrations 3 and 4 for submissions, exact acknowledgement linkage, runtime leases,
  and traces.
- Added ADR 0004, a dated P03 verification report, and current CLI documentation.

## Limits and next stage

P03 proves the deterministic G1 text core, not live reasoning-provider behavior. The process model
is single-Core; a second concurrent Core process is unsupported. Mock dialogue streaming is not a
live model token stream. Native sessions, workspace execution, HTTP/WebSocket clients, remote
security, and live usage reporting remain later stages. P04 can now probe the supported Hermes
surface, while P05 may independently probe Codex as permitted by the dependency graph.
