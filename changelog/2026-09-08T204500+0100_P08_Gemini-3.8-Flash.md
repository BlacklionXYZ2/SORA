## Changes originally implemented

### API configuration and security

- Added `ApiServerConfig` with loopback-address validation, authentication-token bounds, and an allowed-origin list.
- Added constant-time bearer-token authentication.
- Added URL query credential checks and Host/Origin validation.

### Native protocol engine

- Added HTTP request parsing and response serialization.
- Added a WebSocket session using `asyncio.StreamReader` and `asyncio.StreamWriter`.
- Added WebSocket upgrade detection and response generation.

### Event broadcasting, replay, and snapshots

- Added per-client event subscriptions and bounded queues.
- Added ascending replay from the persistent SQLite event table.
- Added stream-bound discovery and authoritative state snapshots for resynchronization.

### Routes and projections

- Added liveness, readiness, and status endpoints.
- Added task submission, listing, lookup, steering, and cancellation endpoints.
- Added conversation-message endpoints.
- Added workspace diff, validation, integration, and rollback endpoints.
- Added companion, settings, desktop-object, and capability projections.
- Added built-in integration and desktop-component registration with enable/disable endpoints.

### Server, client, and CLI

- Added the asynchronous TCP API server and SQLite outbox event pump.
- Added the asynchronous HTTP client and reconnectable WebSocket event stream.
- Added `--serve`, `--api-host`, `--api-port`, `--api-token`, and `--api-token-file` CLI flags.

### Original tests

- Added six API test modules covering protocol/authentication, routes, client supervision/restart, companion projections, replay/reconnect, and extension affordances.
