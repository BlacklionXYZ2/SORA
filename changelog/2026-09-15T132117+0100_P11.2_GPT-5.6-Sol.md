  action effects, polling, verification, controller requirements and cleanup.
- Added a generic deterministic `EmbodimentInteractionController` covering Navigate, Align, Reach,
  Contact, SemanticEffect, Verify and Retract without action-specific switches.
- Separated semantic-effect start from polling so a pending effect is never blindly started again.
- Added explicit completed, cancelled, failed and unknown-outcome terminal states.
- Added connection, deadline and target-validity checks before pending effects.
- Added atomic locomotion/gaze/reach ownership through `PresentationOwnershipArbiter`.
- Guaranteed claim release and controller finalization across cancellation, timeout, target loss,
  disconnect, phase failure, retraction failure and cleanup exceptions.
- Added `AvatarInteractionEnvironment` to adapt the generic lifecycle to P11.1's semantic profile,
  gaze and reach layers without giving presentation code an OS-effect capability.
- Added immediate reach abort/restoration for disconnect cleanup.
- Added five Unity PlayMode lifecycle fixtures covering POINT/PRESS parity, newly registered actions,
  simultaneous ownership grabs, cancellation, timeout, target loss, disconnect, pending-effect
  deduplication, unknown outcomes, cleanup exceptions and disconnect during retraction.
