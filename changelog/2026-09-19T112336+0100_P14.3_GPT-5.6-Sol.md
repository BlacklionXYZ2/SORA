# P14.3 barge-in — GPT-5.6 Sol

Completed: **2026-09-19 11:23:36 +01:00**.

## Changes

- Added strict, idempotent interruption contracts for `barge_in`, `stop_speaking` and
  `cancel_response`, plus an `interrupted` transcript disposition.
- Added Core-owned per-session generation controls. Barge-in and explicit cancellation terminate a
  cooperative dialogue coroutine, while stop-speaking leaves it running.
- Added monotonic output epochs to session snapshots and playback commands. Every effective
  interruption invalidates queued/playing output and prevents a late generation from creating audio.
- Protected the atomic commit boundary: once provider generation has completed, a durable turn
  finishes committing silently rather than being partially written or falsely reported as rolled
  back.
- Moved client synthesis/playback to a background task so microphone processing remains available.
  Fresh speech automatically barges into an active generation or playback.
- Added immediate local speaker abort and a lip-sync reset seam for interruption, completion,
  playback failure, device loss and session close.
- Added an authenticated `/interrupt` endpoint, SDK and client-transport support, with the persisted
  exact voice-session grant rechecked on every request.
- Added concurrency and adversarial acceptance tests for cancellation before persistence,
  output-only silent completion, queued-audio invalidation, duplicate delivery, revoked authority,
  stale TTS chunks, local presentation reset and automatic new-speech barge-in.
- Published interruption request/result schemas and integrated P14.3 into the README and roadmap.

## Boundary

Dialogue cancellation is cooperative through Python's asynchronous cancellation contract. A provider
must not swallow cancellation indefinitely. Once generation has already produced its answer and the
atomic database commit has begun, SORA preserves that canonical turn but still suppresses every audio
and presentation side effect. Timed visemes and mouth/emotion synchronization remain P14.4.
