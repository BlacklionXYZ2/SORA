# P14.2 streaming voice sessions — GPT-5.6 Sol

Completed: **2026-09-19 11:07:22 +01:00**.

## Changes

- Added strict public contracts for voice sessions, semantic transcript updates, device state,
  playback state, expiring playback commands and turn results. Raw PCM and caller-supplied authority
  are structurally absent.
- Added a bounded Core-owned session coordinator with exact event sequencing, device generations,
  volatile partial transcripts, playback lifecycle validation and playback-start-aware echo
  suppression.
- Added a client-local adapter seam for audio frames, VAD, STT, TTS and speaker playback. Only
  semantic transcript/device/playback events cross the Core transport.
- Added exact reusable voice-session authorization and authenticated HTTP/SDK endpoints. Core
  rechecks the persisted grant before every session update.
- Added schema migration 6 and an atomic repository operation that writes one finalized user message,
  one assistant reply and one durable utterance receipt. Concurrent delivery, reconnect and restart
  retries return the existing receipt without repeating dialogue or playback.
- Added deterministic integration and adversarial tests for privacy, partial volatility, exactly-once
  delivery, restart recovery, echo suppression, device loss/recovery, revocation, API routing and the
  complete client-local VAD/STT/TTS/playback seam.
- Published seven voice contract schemas and integrated the completed stage into the README and
  implementation plan.
